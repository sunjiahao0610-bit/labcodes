# 模块一实验报告：虚拟内存页操作

## [PROMPT] 做什么、改哪里、怎么改

- **做什么**：实现内核页表的页插入与页删除，正确维护 `struct Page` 引用计数和 TLB 一致性。
- **改哪里**：`code/kern/mm/pmm.c`
  - `int page_insert(pde_t *pgdir, struct Page *page, uintptr_t la, uint32_t perm);`
  - `void page_remove(pde_t *pgdir, uintptr_t la);`
  - 复用文件内已有的 `static inline void page_remove_pte(...)`。
- **怎么改**：
  1. `page_insert` 用 `get_pte(pgdir, la, 1)` 获取或创建 PTE；失败返回 `-E_NO_MEM`。
  2. 新页先 `page_ref_inc(page)`；若原 PTE 有效且指向同一页，回退这次引用计数；否则先解除旧映射。
  3. 写入新 PTE：`pte_create(page2ppn(page), PTE_V | perm)`，再 `tlb_invalidate`。
  4. `page_remove` 用 `get_pte(pgdir, la, 0)` 查找 PTE，不创建页表；有效则减引用，引用为 0 时释放物理页，清空 PTE 并刷新 TLB。

## [RELY] 可以依赖什么

- **宏**：`PTE_V`、`PTE_U`、`PTE_R`、`PTE_W`、`PTE_X`、`PGSIZE`
- **类型**：`pde_t`、`pte_t`、`uintptr_t`、`struct Page`
- **已有函数/宏**：
  - `get_pte(pgdir, la, create)`：返回 PTE 指针；`create=1` 时分配中间页表，失败返回 `NULL`
  - `pte_create(ppn, flags)`、`page2ppn(page)`、`pte2page(pte)`
  - `page_ref(page)`、`page_ref_inc(page)`、`page_ref_dec(page)`
  - `free_page(page)`、`tlb_invalidate(pgdir, la)`
  - 错误码 `E_NO_MEM`
- **约束**：非叶子 PTE 只置 `PTE_V`；`PTE_U/R/W/X` 只放在叶子 PTE 上。

## [GUARANTEE] 必须实现或修改什么

| 函数 | 位置 | 交付要求 |
|---|---|---|
| `int page_insert(pde_t *pgdir, struct Page *page, uintptr_t la, uint32_t perm)` | `kern/mm/pmm.c` | 建立或更新 `la -> page` 映射；成功返回 `0`，分配失败返回 `-E_NO_MEM` |
| `void page_remove(pde_t *pgdir, uintptr_t la)` | `kern/mm/pmm.c` | 解除 `la` 的映射，正确维护引用计数并刷新 TLB |

内部辅助：`page_remove_pte(pgdir, la, ptep)`，负责“减引用、按需释放物理页、清 PTE、刷 TLB”。

## [SPECIFICATION] 每个函数的详细行为规格

### `page_insert`

```c
int page_insert(pde_t *pgdir, struct Page *page, uintptr_t la, uint32_t perm);
```

**输入**

- `pgdir`：页表根（内核虚拟地址）
- `page`：要映射的物理页描述符
- `la`：线性地址
- `perm`：叶子 PTE 权限位，例如 `PTE_U | PTE_W | PTE_R`

**行为**

1. `ptep = get_pte(pgdir, la, 1)`。
2. 若 `ptep == NULL`，返回 `-E_NO_MEM`。
3. `page_ref_inc(page)`。
4. 若 `*ptep & PTE_V`：
   - 旧页 `p = pte2page(*ptep)`；
   - 若 `p == page`，执行 `page_ref_dec(page)`，避免重复计数；
   - 否则执行 `page_remove_pte(pgdir, la, ptep)`，解除旧映射。
5. `*ptep = pte_create(page2ppn(page), PTE_V | perm)`。
6. `tlb_invalidate(pgdir, la)`。
7. 返回 `0`。

**返回**

- `0`：成功
- `-E_NO_MEM`：中间页表分配失败

**不变量**

- 成功后 `*ptep` 有效，且 `pte2page(*ptep) == page`。
- 同一个 `la` 只保留一个有效映射。
- 旧页的引用计数被正确释放，TLB 已失效。

### `page_remove`

```c
void page_remove(pde_t *pgdir, uintptr_t la);
```

**行为**

1. `ptep = get_pte(pgdir, la, 0)`，只查找，不创建页表。
2. 若 `ptep == NULL`，直接返回。
3. 若 `*ptep & PTE_V`，调用 `page_remove_pte`：
   - `page = pte2page(*ptep)`；
   - `page_ref_dec(page)`；
   - 引用计数为 `0` 时执行 `free_page(page)`；
   - `*ptep = 0`；
   - `tlb_invalidate(pgdir, la)`。

**返回**

- 无返回值。

**边界**

- `la` 未映射：无操作。
- PTE 无效：无操作。
- 只释放被映射的物理页，不释放页表本身。
